# Generative-AI

Python AI & Utility Scripts Collection
A collection of beginner-friendly Python scripts demonstrating basic logic, string manipulation, and randomization. These tools cover everything from email generation to a rule-based chatbot.
🚀 Included Programs
1. AI vs. Human Text Game
An interactive guessing game. The program presents a sentence and asks the user to determine if it was written by a human or generated by an AI.
Key Features: List shuffling, conditional logic, and user input validation.
2. AI Email Generator
A template-based generator that creates professional-looking emails by taking a recipient's name and a specific purpose as input.
Key Features: F-strings for dynamic text insertion and reusable functions.
3. Rule-Based Chatbot
A simple conversational agent designed to answer specific questions about Pragati Engineering College.
Key Features: Dictionary-based response mapping and a continuous while loop for real-time interaction.
4. AI Story Generator
Generates a short narrative based on a single prompt or theme provided by the user.
Key Features: Random selection from pre-defined story templates.
5. Simple Text Summarizer
A basic NLP utility that takes long paragraphs and extracts the first two sentences to create a concise summary.
Key Features: String splitting and joining methods.
6. Creative Username Generator
Generates unique online handles by combining a prefix, a name, a suffix, and a random number.
Example Output: presugasuf12
Key Features: User input concatenation and the random module.
